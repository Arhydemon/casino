# Дым Дым Казино

Учебное desktop-приложение на Python и Flet.

## Что есть

- главное меню;
- рулетка;
- слоты;
- общий баланс;
- статистика игр;
- переключатель звука;
- локальная база SQLite.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Структура

- `main.py` запускает приложение;
- `settings.py` хранит класс `Config`;
- `ui/` отвечает за интерфейс;
- `games/` хранит логику игр;
- `models/` хранит простые классы данных;
- `repositories/` работает с SQLite;
- `services/` связывает состояние, логи и звук.
